# Jordan Barto Portfolio

A personal portfolio built with React and Vite.

## Run locally

```sh
npm ci
npm run dev
```

Run the production build locally with `npm run build`.

## Deploy to GitHub Pages

Run `npm run deploy` to build the site and publish the `dist` folder to the
`gh-pages` branch.

In the repository's **Settings → Pages**, select **Deploy from a branch**, then
choose the `gh-pages` branch and `/ (root)` as the folder. After that one-time
setup, run `npm run deploy` whenever you want to publish an update.

The site is configured for the `Corevirus-ops/portfolio` repository and will be
available at <https://corevirus-ops.github.io/portfolio/>.
