# Jordan Barto Portfolio

A personal portfolio built with React and Vite.

## Run locally

```sh
npm ci
npm run dev
```

Run the production build locally with `npm run build`.

## Deploy to GitHub Pages

The site is configured for the `Corevirus-ops/portfolio` repository and is
published at <https://corevirus-ops.github.io/portfolio/>.

GitHub Actions builds and deploys the site whenever changes are pushed to
`main`. In the repository settings, open **Pages** and set the build and
deployment source to **GitHub Actions**. The workflow is also available to run
manually from the **Actions** tab.
